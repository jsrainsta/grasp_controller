## 两版共有的改动

1. 普通入口先按常规俯仰范围 −90°～−60° 规划。常规无完整路径时，使用同一次观测和同一组起始关节反馈，自动试 −90°～−55°。选中配置会传到细接近和试提。−55° 是搜索上限，2 号舵机的转腕仍是预览。
2. 预接近比较多个悬停高度和俯仰，优先选择盒顶净空更大的候选。抬高后用新关节回读重新检查 3.00 cm 净空。四轮历史记录的名义最小净空改善到约 3.16～3.22 cm，把历史关节偏差套到新路径的压力回放仍有低于 3.00 cm 的情况。
3. 细接近补偿按关节区分运动方向，换向时清除该关节上一方向的偏差。历史 3 号舵机案例中，原目标 203，旧补偿下发 198，回读 191。换向规则的离线回放下发 203，实际稳定位置需要实测。

## Windows 启动

分别解压到两个新目录。将终端切换到要测试的包根目录。新目录可用已有 Python 3.13 环境安装 `requirements-windows.txt`，或者在该目录用 Python 3.13 创建 `.venv` 再安装。启动前确认树莓派服务和 SSH 转发已就绪，本机接口为 `127.0.0.1:18000`，K210 配置自动选串口、230400 波特率。实机从已确认的观察位、空爪张开状态开始。

```cmd
.\.venv\Scripts\python.exe -X utf8 .\k210_camera\grasp_controller.py --config .\k210_camera\controller_pc_fixed_placement_trial.json --check
.\.venv\Scripts\python.exe -X utf8 .\k210_camera\grasp_controller.py --config .\k210_camera\controller_pc_fixed_placement_trial.json --preview
```

预览成功后，使用新请求编号做一次实机测试。以下命令在 CMD 或 Anaconda Prompt 中运行。

```cmd
.\.venv\Scripts\python.exe -X utf8 .\k210_camera\grasp_controller.py --config .\k210_camera\controller_pc_fixed_placement_trial.json --once grasp_%RANDOM%_%RANDOM% --execute
```
