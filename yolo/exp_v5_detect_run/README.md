# exp_v5_detect 训练与验证

YOLO26n Detect 从 Ultralytics 官方预训练权重开始，在本机 CPU 跑满 100 轮。输入尺寸 416，batch 8，随机种子 26，冻结前 10 层。交付的 `../exp_v5_detect.pt` 来自验证集得分最高的第 91 轮，权重约 5.4 MB。

使用 `medicine-boxes.ndjson` 的原始划分，256 张训练、32 张验证、32 张测试。训练时使用轻量旋转、缩放、色彩增强和 Mosaic。原始照片和标注保留。测试集未参与权重选择，包含 27 张单盒、2 张双盒、3 张背景图。

| 类别 ID | 药名 | 正确框数 | 误报 | 漏检 | 测试 mAP50–95 |
| --- | --- | ---: | ---: | ---: | ---: |
| 0 | 阿昔洛韦乳膏 | 14 | 0 | 0 | 98.1% |
| 1 | 红霉素软膏 | 7 | 0 | 0 | 78.5% |
| 2 | 丁酸氢化可的松乳膏 | 10 | 0 | 0 | 86.3% |

逐图结果使用置信度 0.25、IoU 至少 0.50 且类别一致的匹配条件。31 个框全部匹配，IoU 中位数 0.944，最低 0.642。综合测试 mAP50 为 99.5%，mAP50–95 为 87.6%。本机 CPU 的批量测试中，模型推理平均 18.6 ms/张。

首图可使用检测框做粗定位。红霉素最差样例 `IMG_20261116_180534.jpg` 的框延伸到了药盒右侧背景，准确抓点仍需盒面几何定位。测试集中有与训练集相邻拍摄的近似图片，且仅有两张双盒测试图，需要用独立场景进一步评估泛化。数据检查还发现训练集两张及验证集一张 JPEG 解码告警，使用原有划分训练，测试集未见同类告警。
