# expv4 药盒分割训练与验证

**新板版 [expv4.pt](../expv4.pt) 比 expv3 更贴合盒边；本次测试中，平均边界最准确的是 [100 轮旧数据对照版](runs/control/weights/best.pt)。** 两版均用输入尺寸 384、置信度 0.65。建议下一次现场用同一批新照片并排预览。新板组共训练 38 轮，第 18 轮取得最佳训练验证综合指标，之后 20 轮没有再次提高。仅在新板训练的候选中，验证选中了 75% expv3 权重加 25% 新板最佳权重的版本，已保存为单个可直接加载的 YOLO26n-seg 文件。加载、批量推理和图片输出已在项目电脑验证。

## expv4 改善了多少

| 同一输入、同一参数 | expv3 | expv4 |
|---|---:|---:|
| 新板 4 张图，6 个标注药盒 | 找到 6 个，多报 0 个 | 找到 6 个，多报 0 个 |
| 新板药盒轮廓与人工标注的平均重合度（IoU） | 90.60% | **91.62%** |
| 新板轮廓到人工边界的平均距离 | 4.81 像素 | **4.05 像素** |
| 新板药盒掩膜中落在人工边界外的平均比例 | 4.79% | **4.54%** |
| 新板 6 个识别结果的最低置信度 | 0.925 | 0.942 |
| 新板无盒裁切误报 | 0 / 4 | 0 / 4 |
| 历史标注原图（11 张有盒、2 张空板） | 找到 11 个，多报 0 个 | 找到 11 个，多报 0 个 |
| 历史已匹配药盒平均 IoU | 92.74% | **93.18%** |
| 历史已匹配药盒掩膜落在标注外的比例 | **4.63%** | 5.00% |

盒边平均距离按原始 640×480 图片计算，取预测边界到最近人工边界和反向距离的均值。落在标注外的部分可能包含标定板、台面或其他背景。新板样本中，seq8 白盒改善最明显，IoU 从 89.2% 提高到 93.1%；seq11 左边缘蓝盒有退步，IoU 从 92.1% 降到 90.5%，掩膜越界比例从 7.4% 增至 9.3%。绿线是人工标注，紫线是模型预测。[逐张对照图](results/comparison.jpg)

用户提供的 `test_images.zip` 共 113 张历史帧。沿用上轮已核查 JPEG 质量和标定板标记的索引，并逐一核对压缩包内图片的内容哈希，得到 99 张可比帧。两代模型在这 99 张上每帧都输出一个盒子。在能检查标记的 90 张里，两者均未出现掩膜覆盖某个可见标记过半的情况。这组照片没有逐像素人工标注，属于旧场景回放。

本轮新板测试集中四张都是有盒原图，另外四张空背景是从这些原图裁出的无盒区域。现场完整空板的误报率、其他光照下低于 0.7 的药盒、实际抓取成功率，都还需要新的实拍来确认。建议现场优先复查 seq11 那样的左边缘摆位。

## 这次比较什么

旧数据对照组跑完了 100 轮。新板测试中，这组同样找到 6/6 个药盒、额外误报 0 个；平均 IoU 为 **93.75%**，平均边界偏差 **2.76 像素**。它在旧板标注图上的平均 IoU 也达到 93.84%。如果也取 25% 对照组权重与 expv3 混合，新板测试为 92.12% 和 3.85 像素。新板版在这些照片上优于原 expv3，但这次对照未显示补入这批相似的新板摆位比单用旧样本长训练更好。测试照片少，仍值得比较新摆位下的表现。[对照组逐图结果](results/control.json) · [相同混合比例的对照](results/control_blend.json)

重点是药盒靠近新标定板边缘时，分割轮廓会不会把板子也圈进来。基线是项目中的 `yolo/expv3.pt`，它与上一轮推荐的混合训练权重 SHA-256 一致。三个版本统一用输入尺寸 384、置信度 0.65、原图尺寸掩膜做评估。这样能在同一工作点比较训练前后的变化。

## 用了哪些图

新增 11 张 K210 原图都能在 NDJSON 中找到分割标注。按文件时间、摆位和标注叠图分组，避免把连续几个几乎相同的画面分散到训练和测试里。

| 新图序号 | 用途 | 原因 |
|---|---|---|
| seq1 | 排除 | 画面下方还有一只部分露出的盒子，导出记录只标了一个盒子 |
| seq2 | 验证 | 蓝盒斜放，单独留给候选权重评分 |
| seq3–7 | 训练 | 相近的右边缘蓝盒摆位，5 张放在同一组 |
| seq8–11 | 最终测试 | 白盒、双盒和左边缘蓝盒，合计 4 张、6 个已标实例 |

旧模型已经学过上轮 244 张训练样本。本轮抽取固定的 94 张旧样本复习，涵盖手机原图、真实 K210 图、空板裁切、公开药盒及合成图。加入新增训练图时，从这 5 张训练画面的无盒区域裁出板面，生成 8 张空背景，另把已有分割轮廓的药盒贴到板面附近，生成 37 张有盒训练图。训练和验证清单及最终新板测试图之间已检查文件内容哈希，无完全相同的照片跨组。5 张新板训练图来自同一类摆位，合成图也重复使用这个背景。

## 如何训练和选权重

- **长训练对照**从 expv3 出发，只复习 94 张旧图。
- **新板训练**从同一权重出发，用相同的 94 张旧图，再加 5 张新板实拍和 45 张派生图，共 144 张。
- 两组都使用 YOLO26n-seg、Ultralytics、CPU、batch 8、AdamW、初始学习率 0.00035，冻结前 10 层。上限 100 轮，验证指标连续 20 轮没有刷新最佳值时允许早停。新板组每轮看到的图片更多，因此两组更新总次数也不同。
- 为兼顾旧板，在新板组最佳权重和 expv3 之间另外比较了 25%、50%、75% 三个新权重占比。仅用 33 张旧验证图和 seq2 挑选新候选。验证评分将各成功匹配实例的 IoU 总和除以标注实例数加多报数，旧验证图和新验证图权重分别为 70% 和 30%。新板验证只有一个摆位，这个分数容易受该图影响。

